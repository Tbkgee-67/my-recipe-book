Google setup instructions
  1. Create a project in Google Cloud Console.
  2. Enable Google Drive API and configure OAuth consent.
  3. Create an OAuth Client ID for a Web application.
  4. Add your app's exact HTTPS address as an authorized JavaScript origin.
  5. Paste the Client ID here. Never enter a client secret.
