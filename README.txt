MY RECIPE BOOK — NUTRITION SECTION UPDATE

Updates:
- Replaces the old “Notes / source / calories” field label with separate Nutrition and Notes fields.
- Nutrition is saved independently, shown as its own section on the recipe page, and included when editing recipes.
- PDF/text recipe import recognizes Nutrition, Nutrition Facts, Nutritional Information, Nutrition Information, and Per Serving headings and places that content in the Nutrition field.
- Existing recipe notes remain separate; old recipe data is not intentionally deleted.

Install:
1. Back up your recipes first using Import & backup.
2. Extract this ZIP.
3. Upload files to the root of your GitHub repository.
4. Replace index.html, manifest.webmanifest, and sw.js; keep the icons folder and unrelated files.
5. Review imported nutrition details before saving. The app does not independently calculate or verify nutrition values.
