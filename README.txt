MY RECIPE BOOK — COMPLETE APP PACKAGE

Files included:
- index.html — complete recipe book app
- manifest.webmanifest — home-screen install settings
- sw.js — offline app shell
- icons/icon-192.png and icons/icon-512.png — app icons

FEATURES
- Add, edit, delete and search recipes
- Browse by category, with counts and custom categories
- Recipe photos from camera or photo library
- Print-friendly recipe view
- Shopping list with check-off and ingredient transfer
- Import TXT/JSON/Markdown/CSV/HTML/email text; PDF text import (first use needs internet)
- Import from supported recipe URLs
- Scan printed recipes with OCR (first use needs internet)
- Download and restore JSON backups
- Optional Google Drive sync using your own OAuth Web Client ID
- Offline app shell after first online visit

IMPORTANT DATA NOTE
The app uses the existing local browser storage keys:
myRecipeBook_v1, myRecipeBook_shop_v1, myRecipeBook_deleted_v1
This is intended to keep recipes already saved in this same browser and at the same site address. Still, download a backup from your current app before replacing files if possible.

MANUAL GITHUB INSTALL
1. Download and unzip this package.
2. Open your GitHub repository in Chrome and open the main branch.
3. Upload the CONTENTS of this package to the repository root, including the icons folder.
4. When GitHub asks, confirm replacement of index.html, manifest.webmanifest, and sw.js.
5. Do not delete other repository files or folders.
6. Commit the changes in GitHub.
7. Open your GitHub Pages app in Chrome and refresh. If the old version appears, close the tab, reopen it, and refresh again.

This package does not upload anything to GitHub automatically.
