Backup and restore

Export creates a JSON backup that you can save in Downloads or Google Drive. Restore it here later.

Gmail and automatic Google Drive syncing need secure account permissions and additional setup; this starter version does not sign in to those services automatically.

Google Drive sync

Recipes remain saved on this device when offline. Use Sync Now when connected to merge this device with a backup stored in your Google Drive app data.

One-time setup required: create a Google Cloud project, enable Google Drive API, configure an OAuth client for a web app, and add your hosted app's HTTPS origin as an authorized JavaScript origin. Do not enter your Google password here.

Install on Samsung S25

After this app is hosted securely (HTTPS), open its address in Chrome on your phone, tap ⋮ → Add to Home screen or Install app, then confirm. It will get its own home-screen icon and can open offline after the first visit.
