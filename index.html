☁️ Sync Everywhere

Keep recipes, photos, shopping items, and deletions in sync across devices using your private Google Drive app-data storage. Your recipes remain saved locally and work offline. Google sign-in must be authorized on each device/browser session.

Not connected. Set up a Google OAuth Web Client ID to enable cloud sync.

One-time Google setup instructions
  1. Open Google Cloud Console and create/select a project.
  2. Enable the Google Drive API and configure Google Auth Platform / OAuth consent.
  3. Create an OAuth Client ID for a Web application.
  4. Add the exact HTTPS origin of your GitHub Pages app to Authorized JavaScript origins.
  5. Paste the Client ID above and press Connect Google & sync. Never enter a client secret here.

This app stores the backup in Drive's private appDataFolder. OAuth access tokens are held in memory for the current session, not saved as passwords.

Backup and restore

Export creates a JSON backup file that you can save in Downloads or another folder. Restore it here later.

Install on Samsung S25

After this app is hosted securely (HTTPS), open its address in Chrome on your phone, tap ⋮ → Add to Home screen or Install app, then confirm. It can open offline after the first visit.
