My Recipe Book - GitHub TEST split (phase 1)

Files:
- index.html: app markup and all original JavaScript, kept byte-for-byte in the same order.
- styles.css: all 29 actual HTML style blocks, combined in their original order.

Testing instructions:
1. Upload BOTH index.html and styles.css into the same new GitHub testing directory.
2. Copy the app's existing image/icon assets and manifest/service-worker files into that same directory too, preserving their existing filenames and relative paths.
3. Open the testing directory's index.html URL. Do not replace the live app yet.
4. Test recipe photos after refresh and app reopen, adding/editing/deleting recipes, backups/restore, Google Drive, Quick Tools Close, Baking/Brewing Tools, and dark/light mode.

Safety note: This is only phase 1. JavaScript has deliberately NOT been split yet because several parts depend on execution order and on page elements being present. The source working file remains unchanged.
