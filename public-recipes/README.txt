PUBLIC RECIPES WEBSITE

Upload the entire public-recipes folder into the root of your GitHub repository.
The pages will be available at:
  /public-recipes/index.html
  /public-recipes/baking.html
  /public-recipes/smoking.html
  /public-recipes/brewing.html

Features:
- Public, read-only recipe browsing and search
- Recipe photos included
- Save as PDF: opens the browser print dialog; choose “Save as PDF”
- Print recipe: opens the same print dialog
- Download recipe data: downloads an individual recipe as JSON

Important: JSON download is a portable recipe-data file. It has not been wired to the app's import/restore workflow, so do not restore it as a full backup. This public website does not modify the live app or include cooking history/deleted recipe IDs.
